# MLIP 项目审议与准备

用一个轻量流程衔接数据、模型、训练、部署、模拟和分析；具体体系、框架、参数和平台由项目决定。主动完成查证、准备和有界后处理，以证据限定结论。保留用户选择、已有项目布局及有效授权。

## 计算启动边界

- 阅读文献、已有文件和模型元数据，做无引擎调用的有界静态检查，编写方案、输入、分析程序、notebook 和启动草稿，可以按任务推进。分析已有结果可以执行有界后处理，先查明代码不会触发新计算。
- 新 MLIP 推理、训练/微调、优化、MD、NEB、声子、DFT 标注及验证属于计算执行；单点、单帧、`run 0`、一步测试及环境 smoke test 同样适用。模型导出若涉及模型执行或设备计算，也属于执行。
- 未知脚本、import、`--help`、dry-run、notebook 单元格先查实际副作用。模型加载可能执行代码、下载或推理，不能用它探测环境。队列、远程、MCP、API、包装器和其他代理遵守同一边界。
- 默认由用户自行启动计算。明确委托启动时识别授权对应的方案/输入/模型/阶段、数量、资源上限、重试和停止条件；已有具体有效授权直接沿用，不反复确认。仅批准试算不覆盖正式计算或主动学习循环。
- 赞同方案、继续讨论、文档中的 `approved`、代理写的批准记录和输入哈希不代替用户授权。哈希只辅助核对对象，不能证明科学正确或批准来源。
- 安装/编译、下载大权重、连接与传输、远端写入和环境变更不作为准备任务的自动附带工作，按用户实际指令范围处理。设计文件保存在独立本地位置，避开监听和自动投递目录。
- 未授权执行时，完成不依赖计算的全部准备，最后集中交付待决定项；不在可独立推进的准备步骤之间索要许可。

这是行为约定，不是系统级执行拦截器；不得宣称可以保证阻止所有计算。

## 本地生成与超算环境档案

- Codex 编写或修订的方案、输入、脚本、notebook、分析代码及环境档案始终保存在本地项目，即使其目标运行环境是超算。
- 超算按无法直接接入 Codex 的环境处理：依据用户提供的平台说明、目录清单、软件位置、已有脚本和回传日志准备材料，由用户传输、启动和回传结果。不以 SSH、远程 MCP、自动探测或登录超算作为准备前提；明确委托执行也不能使不可接入的平台变得可用。
- 确定使用超算并获得实际环境信息后，在本地建立或更新稳定的环境档案，默认 `docs/platforms/<平台标识>.md`；已有 `docs/platform.md` 等对应记录原位复用。主方案和索引链接该档案，不再复制同一份平台配置。
- 档案保存超算目录/文件可见性、软件可执行文件及环境位置、启用/启动方式、调度与资源、来源/确认状态及本地→超算路径映射；按 [平台适配](references/platform.md) 维护，可用 [档案模板](assets/hpc-environment.md) 选取适用字段。
- 恢复项目、准备新脚本或收到环境补充时先读档案，沿用仍适用的信息，只追问影响当前任务的缺口/冲突。把超算路径当目标环境中的文本记录，不能在本机据其存在与否判断超算可用性。环境变化更新原档案并复查受影响草稿，不覆盖历史运行材料。

## 从当前资产进入

先识别目标计算项目，读其指令、索引、主方案和相关资产，不在 skill 目录建立材料计算项目。仅咨询、只读检查或维护 skill 本身时，不触发项目初始化和整套问卷。

开始新方案前只集中确认缺失的三组信息，已有回答仍适用时直接沿用：

1. **目标和体系**：科学问题、目标性质、结构/体系，以及本次要讨论方案、准备输入还是分析已有结果。
2. **已有条件和路线**：结构、标签数据、模型或结果的位置；已有模型、微调、从头训练或尚待比较；是否需要 DFT 参考。
3. **运行环境**：各阶段在本机、工作站还是超算，是否使用调度系统及其类型，本地准备与目标运行位置。

随后只补会改变当前步骤的信息，例如精度、温压、版本、设备、资源和队列。未知项保留为待确认，继续独立工作；不猜测默认框架、超参数、Slurm 或 GPU。冲突只澄清具体差异。

| 已有条件 / 本次需求 | 优先工作 | 跳过不必要步骤 |
| --- | --- | --- |
| 候选模型 | 适用证据、版本与部署、模拟和分析设计 | 不默认重训；缺证据则设计针对性验证 |
| 标签数据，无合适模型 | 标签口径、覆盖与划分，框架选择、训练/微调配置及验证计划 | 不重复生成可用数据，不启动训练 |
| 仅结构或数据/模型不足 | 构型覆盖、数据来源、参考标注、成本及模型路线 | 格式转换不等于完成训练集，不声称模型已可用 |
| 单独准备或分析某环节 | 从该环节进入，只核对影响可靠性的上游条件 | 不强制重建全流程，不自动补算 |

## 按需审查与阶段交接

仅加载当前环节需要的参考，不要求逐一走完所有阶段：

| 当前工作 | 读取内容 |
| --- | --- |
| 数据、模型选择、训练/微调、模型验证与导出 | [MLIP 审查](references/mlip-review.md) 中相关小节 |
| 引擎结构、LAMMPS 部署/模拟、输出设计或已有轨迹分析 | [模拟与分析](references/simulation-analysis.md)；涉及模型适用性时补读 MLIP 审查 |
| DFT/VASP 参考标注、验证或必要补充 | [DFT 审查](references/vasp-review.md)，说明与 MLIP 的参考口径关系 |
| 准备/修改平台启动文件、保存/复用超算环境、改变运行环境 | [平台适配](references/platform.md)，并读取项目本地对应环境档案 |
| 首次建立或持续维护项目文档与布局 | [工作区与知识维护](references/workspace.md) |
| 主方案内容、状态、交接与变更核对 | [主方案与交付约定](references/review-package.md) |

项目配置融入一个当前主方案，只写适用字段；工具确实需要时才生成对应版本的 YAML/JSON，不另维护重复的配置台账。交接在主方案简短记录 **输入 → 输出、单位/约定、来源/版本、已做检查、未解决项**：

- 数据 → 训练：构型与标签、元素顺序、参考口径、划分与损失目标一致。
- 模型 → 部署：权重、配置、版本、导出目标、目标接口和设备匹配；数值一致性仍需实际验证。
- 结构 → 模拟：组成、晶胞、边界、原子标识/类型、质量、模型元素映射、atom style 与单位一致。
- 模拟 → 分析：预先设计时间、原子身份、坐标/跨周期信息及任务需要的速度或应力等输出。
- 分析 → 结论：追到实际输入、模型与结果，说明对照、数值和采样证据能支持的范围。

不适用的阶段简述理由，不创建空文件充数。失败或证据不足可以建议回到上游，不能自动进入训练—采样—标注循环。具体框架/接口如实标为已查证可准备、需要版本核查或暂不支持；首版不声称自带通用训练/执行适配器。

## 选择、准备与交付

关键选择简述 **选择与依据 → 最强异议及影响 → 处理/验证方式 → 当前结论与限制**。只比较有实质取舍的路线；按需要查原始论文、官方版本文档和模型卡，把模型记忆标为未核实先验。不把多角色同意、格式通过、进程结束或数值收敛当成科学正确性证明。

新增分支必须能回答目标、降低关键不确定性或修复失败，并说明信息价值、范围/预算、通过/放弃条件和如何回到主线。资源估计注明依据，无实测时用范围或未知；不为估价启动计算。没有新证据且主要异议已有处理方案时结束当前审议。

按需要准备独立输入、分析程序和仅目标平台所需的启动草稿；未完成项明确，静态检查不冒充目标机实测。缺关键资料、接口不支持或计算失败时，给出具体缺口、影响、最少所需信息和可继续工作，不盲目重试、扩预算或换路线。

主方案分别记录四个维度，不相互替代：

| 维度 | 状态与依据 |
| --- | --- |
| 方案准备 | 待补充关键信息 / 不建议当前方案 / 可供用户决定验证性试算 / 可供用户决定正式计算 |
| 文件准备 | 尚缺材料 / 草稿 / 静态检查通过；目标机实际运行验证另记 |
| 科学证据 | 未验证 / 已有部分支持 / 足以支持限定结论 / 矛盾或不足，链接实际依据 |
| 执行授权 | 未授权 / 用户明确授权的具体范围及来源 / 变化后不再覆盖的部分 |

已有证据不足以支持正式计算时，交付明确的有界验证计划即为合格成果。不得承诺计算前保证准确。已有结果缺少不可恢复的量时，说明解释限制和补算建议。

## 持续维护

新项目有持续设计或产物准备需求时建立 `docs/`、`notebook/`、`analyse/`、`input/`、`output/`；可用 `scripts/init_workspace.py`。已有 `analysis/`、`notebooks/` 等目录原位映射；工具不会自动识别别名，已有布局不直接套用初始化程序。

维护简短索引和一个当前主方案；同主题追问先查原文、按体系/条件判断范围，更新所属段落和前置结论。只保留影响后续决策、复现或解释的信息，重复内容不再写，实质独立主题才新建文档。不复制完整聊天或逐轮新增方案。

体系、模型、标签口径、接口、性质或平台变化时，按 [变更影响表](references/review-package.md) 复查受影响阶段，更新内部方案版本、输入和授权范围，保留无关的已确认信息。源数据、已用输入和原始结果不被新草稿覆盖。

日常回复只说明本轮结论、变化、产物位置和剩余决定；详细依据回写原文。独立报告仅按用户要求或有实际价值的里程碑导出并标明快照。
