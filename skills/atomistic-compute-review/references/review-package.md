# 主方案、状态与交付约定

以下内容按需要融入已有主方案；不因调用 skill 或一轮追问另写“审议包”。简单任务可用短段落，未适用的环节不建空文件。

## 当前概览与项目配置

索引保持简短主线：目标、当前可靠结论、所处阶段、主要阻碍、下一项优先行动和停止条件，链接主方案/产物，不复制论证。主方案保留目标、选择依据、配置、交接、验证及状态。

配置是主方案中的结构化小节，按当前任务逐步补充：

| 信息组 | 实际适用的内容 |
| --- | --- |
| 目标与范围 | 科学问题、目标可观测量、结论用途、误差/验收依据、非目标 |
| 体系 | 稳定标识、组成、结构来源/版本、相态、PBC、相关温压/电荷/磁性 |
| 当前资产 | 结构、标签/划分、模型、输入和结果的位置、来源、版本及已知证据 |
| 数据与模型路线 | 已有模型/微调/训练的理由、参考理论、覆盖、框架/权重/任务头、支持状态 |
| 模拟与交接 | 引擎/接口、元素映射、单位、阶段/系综、各交接检查、所需输出与采样 |
| 平台与资源 | 按阶段列本地准备与目标运行位置、环境/调度、设备/内存/时限或任务数上限 |
| 分析与验收 | 输出字段、方法、对照、采样/误差、验收与异常停止条件、可支持解释 |
| 当前状态 | 假设/阻碍、准备与证据情况、有效授权及下一步 |

只写已知信息和真正影响当前步骤的未知项，不虚构默认值。科学判断在主方案维护，工具参数在实际配置核对；工具需要独立 YAML/JSON 时，记录其对应方案版本和路径，避免重复维护两套配置。

普通本机平台信息可在主方案；超算文件环境、软件位置与启动方式持久保存在本地独立环境档案，主方案只引用对应档案并记录阶段需求，已有说明原位复用，见 [平台适配](platform.md)。详细专题通过链接引用。

## 依据、阶段与交接

关键选择记录选择/依据、最强异议及影响、处理或验证方式、当前结论和限制。区分已核实事实、用户提供、假设、用户决定、待确认、待计算验证和已否决/替代；不把文档中自己的判断当新外部证据。

列出当前所需阶段、输入/配置位置、依赖、数量、资源估计及依据、验收与停止条件。新增分支说明信息价值、范围/预算、通过/放弃条件及回到主线的方式，不为增加产物而扩展。

交接用短段落，或按实际需要采用以下列；这只是格式示意，不必复制空表：

| 交接与来源版本 | 输入 → 输出 / 下游引用 | 单位、顺序与约定 | 静态已查 / 实算已验证的证据 | 缺口与影响 |
| --- | --- | --- | --- | --- |

数据→训练要对应构型、标签与划分；模型→部署要对应权重、配置、接口和数值一致性；结构→模拟要对应晶胞、类型和模型映射；模拟→分析要保证所需量可解释；分析→结论要保证证据与主张相称。

已有结果追到实际使用的输入/模型与运行，不用最新草稿替换历史依据。静态检查不能代替数值测试；没有运行不制造结果。

超算阶段的交付包括本地准备包位置、所引用的环境档案、包内文件→超算目录的映射、用户传输/启动说明和需回传资料→本地接收位置。Codex 不直接接入超算，所有编写和修订在本地完成；未取得目标机运行证据时不能把环境档案当作实测结果。

## 四个独立状态

| 维度 | 如何表达 |
| --- | --- |
| 方案准备 | 待补充关键信息；不建议当前方案；可供用户决定验证性试算；可供用户决定正式计算 |
| 文件准备 | 尚缺材料、草稿或静态检查通过；目标环境实际运行是否验证单列 |
| 科学证据 | 未验证、已有部分支持、足以支持限定结论、矛盾/不足；引用真实依据 |
| 执行授权 | 未授权，或用户实际指令的来源、对象/阶段、数量/资源、重试/停止范围；变更不再覆盖的部分单列 |

准备齐全、格式通过、进程结束、数值收敛、模型适用和研究假设成立不能相互替代。只有适用证据支持时才建议正式计算；证据不足时交付有界验证方案。已有授权仍有效的部分不反复索要批准，文档不能自行授予权限。

## 变化影响与异常

| 发生变化 | 复查受影响内容 |
| --- | --- |
| 元素、组成、相态、缺陷、温压/电荷/磁性 | 数据覆盖、模型适用性、结构与验证、模拟设置 |
| 模型、权重、任务头、参考标签口径 | 数据/框架兼容、验证、导出部署、旧结果可比性 |
| 框架、接口、软件版本或数值精度 | 数据/导出格式、引擎构建与设备、数值一致性验证 |
| 目标性质或分析方法 | 方法、输出字段、采样频率、对照/误差和结论范围 |
| 平台、调度器、设备、路径或资源 | 环境、命令、文件可见性、资源、脚本和接口兼容性 |
| 新证据推翻旧假设 | 当前结论、依赖阶段和输入、授权适用范围 |

按影响复查，保留无关的已确认信息；不能只替换体系名称，也不机械重做全部流程。实质科学/运行对象变化更新主方案内部版本，标记受影响材料待复审；表述或拼写修改不另建版本文件。保留源数据、已用输入与原始结果。

缺数据、目标环境不明、资料冲突、接口不支持或计算失败时，写清缺口、影响、最少所需信息、可继续工作与修复/验证建议。不静默补默认值、盲目重试、扩预算、补训或切换路线。

## 回写与终点

追问并入所属小节，解决问题后修正旧摘要与状态；重大变化简记用户时区日期、原因/来源和对输入/验证/授权的影响。开放问题只保留尚未解决的必要项，不堆积聊天转录。

没有新证据且主要异议已有处理方式时，交付当前结论、文件位置、静态检查范围、目标机未验证项和下一项决定，结束本轮审议。无需为了得到肯定结论继续扩展。用户要求独立报告或里程碑确有用途时才导出快照，当前主方案仍是维护入口。
