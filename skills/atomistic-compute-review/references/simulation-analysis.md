# 结构、模拟与已有结果分析

LAMMPS 是重点接口；用户选择其他引擎时按其已核实版本适配，不强制迁移。只准备或分析当前任务需要的部分，计算边界以主 skill 为准。

## 1. 结构到引擎输入

先核对来源和处理记录：稳定体系标识、组成/原子数、晶胞与周期性、坐标基底、原子身份、类型/元素顺序、质量及适用的电荷/拓扑。超胞、缺陷、表面、约束等操作记录其目的与来源。

转换前后核对物理等价性及原子映射；晶胞旋转或三斜盒转换时，相关坐标/向量/张量按需要同步处理。不用重排后丢失的行号替代原子身份，不静默接受元素/类型交换。

LAMMPS 输入按实际模型与构建核查：

- `units` 与模型、数据、时间步长、温压及分析换算一致；不能只改 `units` 一行就宣称整个输入已换算。
- `atom_style` 与数据列和模型需求匹配；不把 `atomic` 当所有模型/体系的默认值。
- 数据类型、质量、模型元素映射和 `pair_coeff` 对应；具体 `pair_style`、参数、插件和后端按目标版本官方说明确定。
- 邻居表、截断、并行/加速限制和边界条件遵从具体接口，不凭其他模型的模板推定兼容。

使用 [read_data](https://docs.lammps.org/read_data.html)、[units](https://docs.lammps.org/units.html) 及所选接口文档查具体语法。可做独立格式解析和静态交叉核对；调用引擎读入、`run 0` 或单帧能量/力检查属于计算执行。

## 2. 模拟设计与预算

从目标量倒推阶段与输出：是否需要优化、平衡、生产段、何种系综/控制方式及边界、时间步长、时长、体系尺寸、采样间隔和重复。参数依据已有证据或待验证假设确定，不预设一套适用于所有体系的 NVT/NPT/时长。

区分模型适用性、积分/有限尺寸敏感性、平衡与采样充分性。对会改变目标判断的检验明确预算、验收与停止条件；出现异常结构、能量/温压异常、超适用域、数值失败或超预算时如何处置要能落实。性能与资源估计注明来源，无实测不冒充实测。

仅生成选定环境所需启动草稿，参见 [平台适配](platform.md)。原生运行目录保留该次已用输入、日志、检查点和结果；新草稿不覆盖旧运行。重启从哪个状态、是否重置时间及重复输出如何识别，写进当前方案。

## 3. 模拟到分析的输出约定

在输入阶段就核对预定分析所需字段。以下按目标选择，不要求全部输出：

| 目标 | 提前约定的资料 | 解释限制 |
| --- | --- | --- |
| 稳定性/平衡诊断 | 时间/步数及步长、能量、温度、体积、适用的压力/应力及阶段标识 | 温度达标或总能稳定不单独证明模型准确或采样充分 |
| 扩散/位移 | 稳定原子 ID、元素/组别、时间、逐帧晶胞、可恢复连续位移的坐标/跨周期信息 | 仅稀疏 wrapped 坐标且无法排除多次跨盒时，不能唯一恢复长时位移 |
| 结构/空间统计 | 元素映射、坐标、晶胞/PBC、选择组、采样与归一化规则 | 不把可视化图片当作足够的结构统计证据 |
| 速度或应力关联 | 任务所需的速度或应力/热流等量、定义/单位、时间分辨率 | 缺失量不能靠现有位置轨迹无条件补出；这些量是否可定义也需核对模型 |
| 相对能量/排序 | 同一比较口径、组成/参考态、结构版本、模型与统计误差依据 | 不兼容零点、条件或不足的采样不能支持排序解释 |

LAMMPS [dump 文档](https://docs.lammps.org/dump.html) 区分 wrapped、unwrapped 坐标与 image flags，且指出未排序的原子行顺序可能跨帧改变。因此分析按 ID 对齐，不能按行号连线。实际输出字段与三斜盒/PBC 处理按目标版本核实；上述说明不是一段通用可运行 dump 模板。

## 4. 有界分析已有结果

1. 读取已有计划、实际输入/模型说明、日志和输出头部，界定文件范围、大小、帧数与分析开销。大轨迹按任务做流式读取或有说明的抽样，不默认全量载入。
2. 核对是否完整结束/截断、缺帧、重复帧、重启时间重置、原子身份、单位、晶胞/PBC 和所需量。进程结束、数值收敛与科学可解释性分别判断。
3. 只运行已知无 calculator、新推理、补算或下载副作用的解析和统计；新写的后处理可在当前任务范围内执行。notebook 逐单元检查，生成不等于执行。
4. 按任务排除平衡段，处理漂移、相关性、采样区间/时间原点、独立重复和适用的误差估计。标明方法与可复现参数；相关帧不能冒充大量独立样本，未校准模型分歧也不能当误差条。
5. 图表与派生数据追到原始文件、帧范围、脚本版本和模型/输入记录。公共代码放项目的分析程序目录，运行分析产物跟随来源运行或沿用既有结果目录，不改写原始结果。
6. 回写限定结论、失败/否定结果和缺口。缺少不可恢复的字段时说明哪些分析仍成立、哪些结论不可支持及未来输出/补算建议；不自动重跑、延长模拟或重训。

完成当前已有结果的可支持分析后结束。模型来源不明时保留其影响，不因此强制用户重建训练项目；确需更多计算时给出能改变判断的最小验证方案。
