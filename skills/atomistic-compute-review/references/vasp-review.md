# VASP / DFT 审查

用于 MLIP 的参考标注、验证或必要补充路线，只审查与目标性质有关的项目；不按检查项数量给科学可靠性打分。数值参数由目标量、体系和所用实现确定，不在本 skill 中硬编码通用“准确参数”。

## 体系和物理模型

- 结构来源、化学计量、周期性、超胞、表面/界面/缺陷的定义和边界条件。
- 研究问题需要的相态、温压、磁性/磁序、电荷，以及这些设置的物理依据。
- 泛函、赝势版本及元素顺序、U、SOC、色散等选择的依据和待验证影响。
- 比较对象的参考态、归一化和计算口径是否一致；不把不兼容的能量直接相减。

## 数值与有限尺寸

- 设计目标可观测量对 ENCUT、k 点、电子/离子收敛条件的检验。
- 按体系检查真空、层数、超胞大小、约束和必要修正。
- 准备输入时核查所用 VASP 版本的官方定义及选项兼容性，不能只照抄通用模板。
- 明确已完成的收敛证据、可迁移的理由和仍需新计算验证的部分。

用于训练/测试标签时，保留结构与帧标识、参考输入/软件版本、计算收敛状态及实际提取的能量/力/适用的应力或 virial。提取前核对单位、符号、分量顺序和归一化，与目标框架的数据约定对应；不把未收敛输出或不同参考口径静默混入同一标签集合。不复制或分发未获授权的赝势材料。

官方入口：[VASP Manual](https://vasp.at/wiki/The_VASP_Manual)、[ENCUT](https://vasp.at/wiki/ENCUT)。按任务查阅相关官方页面，不以链接本身代替查证。

## 计划验收

分别定义进程结束、电子/离子收敛、目标性质收敛和物理解释成立的证据。需要对照、多个起点、路径或有限温度采样时说明原因及预算。

审议阶段设计这些验证，不自动运行 VASP、VASPkit 菜单、ASE calculator、smoke test 或调度器。生成的输入与提交脚本留在独立草稿位置，不能进入自动投递目录。
